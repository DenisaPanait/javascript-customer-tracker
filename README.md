# Customer Tracker (JavaScript)

## Overview
This project is a simple customer tracking system built with JavaScript. It demonstrates how to store, manage, and display customer data using arrays and basic programming logic.

## Features
- Stores customer data in arrays
- Iterates through data using loops
- Displays customer information in the console
- Demonstrates basic data management logic

## Technologies Used
- JavaScript

## How to Run
1. Download or clone this repository
2. Open the JavaScript file in your code editor
3. Run the file in the browser console or using Node.js
4. View the output in the console
